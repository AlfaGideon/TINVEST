# TINVEST — AI Portfolio OS

**Живой демо:** https://alfagideon.github.io/TINVEST/

Профессиональный инвестиционный продукт на Webapp, работает полностью в браузере (GitHub Pages). Без бэкенда, без БД — все данные в LocalStorage, с экспортом/импортом.

### 🚀 Что внутри (рабочий продукт)

**1. Дашборд**
- Общая стоимость, P&L, диверсификация score
- График капитала vs IMOEX (Chart.js) — 1M/3M/1Y/ALL
- Аллокация donut по классам активов
- Топ холдинги + AI Insights live

**2. Портфель**
- Таблица с весом, ценой, P&L, удалением
- История сделок (buy/sell)
- Дивиденды/купоны план + налоговый лайфхак ИИС
- Добавление актива через модалку (тикер, цена, валюта)

**3. Рынки**
- Search по тикерам (NVDA, SBER, BTC, ОФЗ и тд)
- Фильтры: Акции / ETF / Крипта / Облигации
- Watchlist (избранное ★) — LocalStorage
- Кнопка "Купить" добавляет в портфель

**4. AI Аналитика**
- Diversification score (HHI + сектор + класс)
- Sector breakdown с прогресс-барами
- Корреляция активов (bar chart)
- Risk-meter 0-10 + стресс-тесты 2008/2020/ставка
- Рекомендации: кэш, фиксация, ETF, налоговая оптимизация

**5. Калькуляторы**
- Сложный процент (начальный + ежемесячный + ставка)
- DCA калькулятор (усреднение)
- Калькулятор цели (через сколько достигнете)

**6. Цели**
- 3 демо-цели: квартира, подушка, FIRE
- Прогресс-бар, добавление/удаление, хранение в LocalStorage

### 🛠 Технологии
- Чистый HTML/CSS/JS, no build needed — работает на GitHub Pages и при открытии `index.html` напрямую
- Chart.js CDN, Inter font, CSS variables, Responsive, PWA manifest
- LocalStorage key: `tinvest_v2`
- Демо-данные: 7 активов (NVDA, SBER, YDEX, VOO, BTC, ОФЗ, LQDT) + 14 инструментов в маркете
- Подготовка к подключению брокерских API (Тинькофф Invest API, Alor)

### 📦 Структура
```
index.html — SPA с 6 вьюхами
assets/style.css — дизайн система (fintech dark)
assets/js/data.js — мок-данные, FX, сектора
assets/js/app.js — логика, метрики, чарты, модалки
manifest.json — PWA
404.html — SPA fallback для Pages
.github/workflows/pages.yml — auto deploy
```

### 🔧 Локальный запуск
```bash
# просто откройте index.html или:
npx serve .
```

### Экспорт/Импорт
Кнопки в сайдбаре — скачивают JSON портфеля. Можно бэкапить и делиться.
