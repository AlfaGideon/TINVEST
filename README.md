# TINVEST — AI Portfolio OS

**Онлайн-приложение (Live Webapp):** https://alfagideon.github.io/TINVEST/

Профессиональный инвестиционный продукт на Webapp, работает полностью в браузере (GitHub Pages). Без бэкенда, без БД — все данные в LocalStorage, с экспортом/импортом.

### 🚀 Что внутри (рабочий продукт)

**1. Дашборд**
- Общая стоимость, P&L, диверсификация score
- График капитала vs IMOEX (Chart.js) — 1M/3M/1Y/ALL
- Аллокация donut по классам активов
- Топ холдинги + AI Insights live
- Виджет «Сигналы Бизнес ФМ & Polymarket» — мгновенные рекомендации продуктов к покупке на основе новостей

**2. Сигналы, Новости & Polymarket — только реальные онлайн-данные**
- **Живая лента новостей**: реальные RSS-ленты Бизнес ФМ, РБК, Интерфакса, ТАСС, Коммерсанта и CoinTelegraph. Автообновление каждые 3 минуты, кликабельные заголовки, авто-детект кодировки (UTF-8/windows-1251), обход CORS через цепочку публичных прокси.
- **Реальный Polymarket**: вероятности, объёмы и дневная динамика рынков предсказаний из публичного Gamma API (`gamma-api.polymarket.com`), обновление каждые 90 секунд.
- **Сигналы без симуляторов**: тематический движок анализирует СВЕЖИЕ заголовки (ставка ЦБ, нефть, золото, крипта, геополитика, банки, металлы) и собирает сигналы по инструментам с живыми котировками MOEX/Binance прямо на карточке.
- **Статус-центр онлайн**: индикаторы доступности каждого источника, время последнего обновления, кнопка «Обновить сейчас». Если источник недоступен — приложение честно показывает это вместо подстановки фейковых данных.
- **Матрица устойчивости портфеля**: оценка защищённости капитала от горячих тем реального новостного потока.
- **Никаких симуляторов**: в модуле нет захардкоженных новостей, демо-сценариев и «AI Симулятора» — только живые данные.

**2. Портфель**
- Таблица с весом, ценой, P&L, удалением
- История сделок (buy/sell)
- Дивиденды/купоны план + налоговый лайфхак ИИС
- Добавление актива через модалку (тикер, цена, валюта)

**3. Рынки & Актуальные стаканы (Live)**
- Search по тикерам (NVDA, SBER, BTC, ОФЗ и тд)
- Фильтры: Акции / ETF / Крипта / Облигации / Внебиржевые OTC
- **Актуальные биржевые и брокерские стаканы** (MOEX ISS, Binance, брокерские OTC) в реальном времени, с кнопкой онлайн-обновления и покупкой из стакана
- Watchlist (избранное ★) — LocalStorage
- Кнопка "Купить" добавляет в портфель

**4. AI Аналитика**
- Diversification score (HHI + сектор + класс)
- Sector breakdown с прогресс-барами
- Корреляция активов (bar chart)
- Risk-meter 0-10 + стресс-тесты 2008/2020/ставка
- Рекомендации: кэш, фиксация, ETF, налоговая оптимизация

**5. Калькуляторы**
- Сложный процент (начальный + ежемесячный + ставка)
- DCA калькулятор (усреднение)
- Калькулятор цели (через сколько достигнете)

**6. Цели**
- 3 умные цели: квартира, подушка, FIRE (хранение в LocalStorage)
- Прогресс-бар, добавление/удаление, хранение в LocalStorage

### 🛠 Технологии
- Чистый HTML/CSS/JS, no build needed — работает на GitHub Pages и при открытии `index.html` напрямую
- Chart.js CDN, Inter font, CSS variables, Responsive, PWA manifest
- LocalStorage key: `tinvest_v2`
- Стартовый каталог: 7 активов + 15 инструментов с реальными онлайн-котировками (MOEX, Binance, ЦБ, Polymarket)
- Подготовка к подключению брокерских API (Тинькофф Invest API, Alor)

### 📦 Структура
```
index.html — SPA с 7 вьюхами
assets/style.css — дизайн система (fintech dark)
assets/js/data.js — каталог инструментов, FX, сектора (без фейковых новостей)
assets/js/news.js — LIVE-движок: реальные RSS-ленты СМИ + Polymarket Gamma API,
  тематический анализ свежих заголовков, автообновление 3 мин/90 сек, без симуляторов
assets/js/app.js — логика портфеля, метрики, чарты, модалки, живые котировки MOEX/Binance/ЦБ
manifest.json — PWA
404.html — SPA fallback для Pages
.github/workflows/pages.yml — auto deploy
```

### 🔧 Локальный запуск
```bash
# просто откройте index.html или:
npx serve .
```

### Экспорт/Импорт
Кнопки в сайдбаре — скачивают JSON портфеля. Можно бэкапить и делиться.
